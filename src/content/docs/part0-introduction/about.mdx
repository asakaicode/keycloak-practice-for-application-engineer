## 対象読者

- 社内やプロジェクトで Keycloak が導入されていて、フロントエンドエンジニアとして
  「とりあえずログイン処理は動いているけれど、裏側で何が起きているのか分かっていない」人
- OAuth 2.0 / OpenID Connect（OIDC）を一度は聞いたことがあるが、
  Realm・Client・トークンといった Keycloak 固有の用語との対応が曖昧な人
- SPA（Vite・React・Vue などのフロントエンドアプリ）から Keycloak を使う実装を、
  自分の手で一度は組んでみたい人

バックエンドエンジニアや Keycloak の運用担当者向けの、サーバー構築・クラスタリング・
高可用性構成などの内容は扱いません。あくまで「フロントエンドから見た Keycloak」に絞っています。

## 対象バージョン

このサイトのハンズオンは、次のバージョンで動作確認をしています（[docker-compose.yml](https://github.com/asakaicode/keycloak-practice-for-application-engineer/blob/main/handson/docker-compose.yml)
で固定）。

- Keycloak: 26.7
- keycloak-js: 26.2.4

Keycloak には LTS がなくリリースが速いため、手元の環境と表示が異なる場合は
[Part 6: 公式ドキュメントの歩き方](/part6-reference/official-docs-guide/) を参考に、
お使いのバージョンの公式ドキュメントも確認してください。

## このサイトの構成

[はじめに](#対象読者) のページの通り、このサイトは「まず動かして、あとから理解する」
構成になっています。

1. **Part 1**: Docker で Keycloak を起動し、サンプル SPA でログインを成功させる（15分）
2. **Part 2**: そのログインの裏側で何が起きていたのかを、OAuth 2.0 / OIDC の概念から理解する
3. **Part 3**: Realm・Client・User を自分の手で作りながら、1つの SPA を育てていく
4. **Part 4**: サードパーティ Cookie 問題や BFF パターンなど、実務で必ず向き合う現実的な課題
5. **Part 5**: 実務で頻発するエラーを、あえて自分で起こしてから直す「エラー体験ラボ」
6. **Part 6**: 用語集・エンドポイント一覧などのリファレンス
