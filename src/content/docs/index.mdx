## このサイトで学べること

<CardGrid stagger>
	<Card title="まず動かす" icon="rocket">
		Docker 1コマンドで Keycloak を起動し、用意済みの SPA でログインを成功させます。
	</Card>
	<Card title="あとから理解する" icon="open-book">
		成功体験のあとに OAuth 2.0 / OIDC の理論を遡って学びます。
	</Card>
	<Card title="1つの SPA を育てる" icon="add-document">
		ログイン → トークン → 権限別 UI → API 保護と、章が進むごとにサンプルを育てます。
	</Card>
	<Card title="エラーをわざと起こして直す" icon="warning">
		redirect_uri 不一致や CORS など、実務で必ず踏むエラーを体験してから直します。
	</Card>
